# รายงานสรุปขั้นตอนการทบทวนสัญญา

เลขที่เอกสาร LEG-CT-016 · เจ้าของเอกสาร ฝ่ายกฎหมายและการกำกับดูแล

## 1. วัตถุประสงค์และภาพรวม

สัญญาทุกฉบับที่บริษัทเป็นคู่สัญญาต้องผ่านการทบทวนจากฝ่ายกฎหมายก่อนลงนาม เพื่อลดความเสี่ยงและให้เงื่อนไขสอดคล้องกับนโยบายของบริษัท โดยกำหนดผู้มีอำนาจลงนามตามมูลค่าสัญญา

- ส่งร่างสัญญาให้ฝ่ายกฎหมายล่วงหน้าอย่างน้อย 5 วันทำการ
- ห้ามลงนามก่อนได้รับอนุมัติครบทุกขั้น
- เก็บสัญญาฉบับสมบูรณ์ในระบบกลางพร้อมวันครบกำหนด

## 2. บทบาทและความรับผิดชอบ

- เจ้าของสัญญา: ระบุเงื่อนไขทางธุรกิจและติดตามการปฏิบัติ
- ฝ่ายกฎหมาย: ตรวจและแก้ไขข้อกำหนดทางกฎหมาย
- ฝ่ายการเงิน: ตรวจเงื่อนไขการชำระเงินและภาษี
- ผู้มีอำนาจลงนาม: ลงนามเมื่อผ่านการทบทวนครบ

## 3. ขั้นตอนการปฏิบัติ

1. ร่างหรือรับร่างสัญญา: ใช้แม่แบบมาตรฐานเมื่อมี
2. ส่งทบทวน: ส่งผ่านระบบพร้อมสรุปเงื่อนไขสำคัญ
3. ทบทวนทางกฎหมายและการเงิน: ตรวจข้อจำกัดความรับผิด การยกเลิก และข้อมูลส่วนบุคคล
4. เจรจาและแก้ไข: บันทึกประเด็นที่ตกลงและเปลี่ยนแปลงทุกครั้ง
5. ลงนาม: ผู้มีอำนาจลงนามและเก็บฉบับจริง
6. ติดตามและต่ออายุ: ระบบแจ้งเตือน 90 วันก่อนสัญญาครบกำหนด

## 4. รายละเอียดและเกณฑ์สำคัญ

| มูลค่าสัญญา (บาท) | ผู้มีอำนาจลงนาม | เวลาทบทวนมาตรฐาน |
|---|---|---|
| ไม่เกิน 100,000 | ผู้อำนวยการฝ่าย | 3 วันทำการ |
| 100,001 - 1,000,000 | ผู้จัดการทั่วไป | 5 วันทำการ |
| 1,000,001 - 10,000,000 | กรรมการผู้จัดการ | 7 วันทำการ |
| เกิน 10,000,000 | คณะกรรมการบริษัท | 10 วันทำการ |

## 5. ตัวชี้วัดผลการดำเนินงาน

- สัญญาที่ทบทวนทันเวลา: เป้าหมาย ไม่น้อยกว่า 90% (รายเดือน)
- สัญญาที่ลงนามโดยไม่ผ่านทบทวน: เป้าหมาย 0 ฉบับ (รายไตรมาส)
- สัญญาที่ครบกำหนดโดยไม่ได้แจ้งเตือน: เป้าหมาย 0 ฉบับ (รายไตรมาส)
- สัญญาที่ใช้แม่แบบมาตรฐาน: เป้าหมาย ไม่น้อยกว่า 70% (รายไตรมาส)

## 6. ความเสี่ยงและมาตรการควบคุม

- ลงนามโดยไม่มีอำนาจ: ตรวจรายชื่อผู้มีอำนาจก่อนลงนาม
- ข้อกำหนดความรับผิดไม่เหมาะสม: ฝ่ายกฎหมายตรวจทุกฉบับ
- สัญญาสูญหาย: เก็บในระบบกลางและสำรองข้อมูล
- ไม่ติดตามวันครบกำหนด: ระบบแจ้งเตือนอัตโนมัติ

## 7. คำถามที่พบบ่อย

**สัญญาที่คู่สัญญาเป็นผู้ร่างต้องทบทวนหรือไม่?** ต้องทบทวนเช่นเดียวกัน

**ข้อตกลงรักษาความลับ (NDA) ใช้แม่แบบใด?** ใช้แม่แบบมาตรฐานของฝ่ายกฎหมาย

**ลงนามอิเล็กทรอนิกส์ได้หรือไม่?** ได้เมื่อใช้ระบบที่ฝ่ายกฎหมายอนุมัติ

**แก้ไขสัญญาหลังลงนามทำอย่างไร?** ทำเป็นข้อตกลงแก้ไขเพิ่มเติมและผ่านการทบทวนอีกครั้ง

**สัญญาเร่งด่วนทำอย่างไร?** แจ้งฝ่ายกฎหมายและขอลดเวลาทบทวนพร้อมเหตุผล
