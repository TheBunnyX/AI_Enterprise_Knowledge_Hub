# รายงานสรุปนโยบายการจัดซื้อจัดจ้าง

เลขที่เอกสาร PUR-PO-004 · เจ้าของเอกสาร ฝ่ายจัดซื้อและพัสดุ

## 1. วัตถุประสงค์และภาพรวม

การจัดซื้อจัดจ้างต้องเป็นไปตามวงเงินและวิธีที่กำหนด เพื่อให้เกิดความโปร่งใสและคุ้มค่า โดยรายการที่มีมูลค่าสูงต้องเปรียบเทียบราคาจากผู้ขายอย่างน้อย 3 ราย

- ผู้ขายรายใหม่ต้องผ่านการประเมินคุณสมบัติก่อนทำสัญญา
- เก็บเอกสารการจัดซื้อไม่น้อยกว่า 5 ปี
- ห้ามแบ่งใบสั่งซื้อเพื่อเลี่ยงวงเงินอนุมัติ

## 2. บทบาทและความรับผิดชอบ

- ผู้ขอซื้อ: ระบุความต้องการ ข้อกำหนด และงบประมาณ
- ฝ่ายจัดซื้อ: เปรียบเทียบราคา เจรจา และออกใบสั่งซื้อ
- ผู้อนุมัติ: อนุมัติตามวงเงินที่กำหนดในตาราง
- ฝ่ายพัสดุ: ตรวจรับสินค้าและบันทึกเข้าคลัง

## 3. ขั้นตอนการปฏิบัติ

1. ยื่นใบขอซื้อ: ผู้ขอซื้อกรอกใบขอซื้อในระบบพร้อมข้อกำหนดและงบประมาณ
2. เปรียบเทียบราคา: ฝ่ายจัดซื้อขอใบเสนอราคาตามจำนวนรายที่วงเงินกำหนด
3. อนุมัติและออกใบสั่งซื้อ: ผู้อนุมัติพิจารณาแล้วฝ่ายจัดซื้อออกใบสั่งซื้อ
4. ติดตามการส่งมอบ: ฝ่ายจัดซื้อติดตามกำหนดส่งและแจ้งผู้ขอซื้อ
5. ตรวจรับ: ฝ่ายพัสดุตรวจรับตามใบสั่งซื้อและบันทึกความไม่ตรงสเปก
6. จ่ายเงินและประเมินผู้ขาย: ฝ่ายบัญชีจ่ายตามเงื่อนไข ฝ่ายจัดซื้อประเมินผู้ขายทุกปี

## 4. รายละเอียดและเกณฑ์สำคัญ

| มูลค่าการจัดซื้อ (บาท) | วิธีจัดซื้อ | ผู้อนุมัติ |
|---|---|---|
| ไม่เกิน 10,000 | ซื้อโดยตรง | หัวหน้างาน |
| 10,001 - 100,000 | เปรียบเทียบราคา 3 ราย | ผู้อำนวยการฝ่าย |
| 100,001 - 1,000,000 | เปรียบเทียบราคา 3 ราย | ผู้จัดการทั่วไป |
| เกิน 1,000,000 | ประกวดราคา | คณะกรรมการบริษัท |

## 5. ตัวชี้วัดผลการดำเนินงาน

- เวลาจากใบขอซื้อถึงใบสั่งซื้อ: เป้าหมาย ไม่เกิน 5 วันทำการ (รายไตรมาส)
- ส่งมอบตรงเวลา: เป้าหมาย ไม่น้อยกว่า 95% (รายไตรมาส)
- การประหยัดงบจากการเจรจา: เป้าหมาย ไม่น้อยกว่า 3% (รายไตรมาส)
- สินค้าถูกส่งคืนเพราะไม่ตรงสเปก: เป้าหมาย ไม่เกิน 2% (รายไตรมาส)

## 6. ความเสี่ยงและมาตรการควบคุม

- ผลประโยชน์ทับซ้อน: ผู้เกี่ยวข้องต้องแจ้งความสัมพันธ์กับผู้ขายก่อนพิจารณา
- พึ่งพาผู้ขายรายเดียว: มีผู้ขายสำรองสำหรับรายการสำคัญ
- ราคาสูงเกินจริง: เทียบราคาตลาดและเจรจาทุกครั้งที่เกิน 100,000 บาท
- เอกสารไม่ครบเมื่อถูกตรวจสอบ: เก็บเอกสารครบชุดในระบบอย่างน้อย 5 ปี

## 7. คำถามที่พบบ่อย

**ซื้อฉุกเฉินต้องทำอย่างไร?** ซื้อก่อนได้ไม่เกิน 20,000 บาทแล้วส่งใบขอซื้อย้อนหลังภายใน 3 วันทำการ

**เลือกผู้ขายรายเดิมโดยไม่เปรียบเทียบราคาได้หรือไม่?** ได้เมื่อมีสัญญากรอบที่ผ่านการอนุมัติและราคายังไม่หมดอายุ

**ผู้ขายรายใหม่ต้องใช้เอกสารอะไร?** หนังสือรับรองบริษัท ภ.พ.20 และบัญชีธนาคารที่ตรงกับชื่อบริษัท

**ใครอนุมัติการจ้างที่ปรึกษา?** ตามมูลค่าสัญญา เหมือนตารางวงเงินจัดซื้อ

**สินค้าชำรุดตอนส่งมอบทำอย่างไร?** ปฏิเสธรับและแจ้งผู้ขายเปลี่ยนภายใน 7 วัน
