# รายงานสรุปแนวทางการใช้แบรนด์และงบการตลาด

เลขที่เอกสาร MKT-BR-008 · เจ้าของเอกสาร ฝ่ายการตลาด

## 1. วัตถุประสงค์และภาพรวม

สื่อการตลาดทุกชิ้นต้องใช้โลโก้ สี และน้ำเสียงตามแนวทางแบรนด์ และต้องผ่านการตรวจจากทีมแบรนด์ก่อนเผยแพร่ งบการตลาดแต่ละแคมเปญต้องได้รับอนุมัติก่อนเริ่มใช้จ่าย

- ใช้โลโก้และสีตามคู่มือแบรนด์เท่านั้น
- สื่อทุกชิ้นผ่านการตรวจจากทีมแบรนด์ก่อนเผยแพร่
- รายงานผลแคมเปญภายใน 14 วันหลังจบแคมเปญ

## 2. บทบาทและความรับผิดชอบ

- ทีมแบรนด์: ดูแลคู่มือแบรนด์และตรวจสื่อ
- ผู้จัดการแคมเปญ: วางแผน งบประมาณ และรายงานผล
- ฝ่ายกฎหมาย: ตรวจข้อความโฆษณาและลิขสิทธิ์
- ฝ่ายการเงิน: ควบคุมงบและจ่ายเงินตามอนุมัติ

## 3. ขั้นตอนการปฏิบัติ

1. เสนอแผนแคมเปญ: ระบุวัตถุประสงค์ กลุ่มเป้าหมาย ช่องทาง และงบประมาณ
2. อนุมัติงบ: ตามตารางวงเงินก่อนเริ่มใช้จ่าย
3. ผลิตสื่อ: ใช้แม่แบบและทรัพยากรแบรนด์ที่ทีมแบรนด์จัดไว้
4. ตรวจสื่อ: ทีมแบรนด์และฝ่ายกฎหมายตรวจภายในเวลาที่กำหนด
5. เผยแพร่และติดตาม: ติดตามผลรายสัปดาห์และปรับงบตามผล
6. สรุปผล: รายงานผลภายใน 14 วันหลังจบแคมเปญ

## 4. รายละเอียดและเกณฑ์สำคัญ

| มูลค่าแคมเปญ (บาท) | ผู้อนุมัติ | เวลาตรวจสื่อ |
|---|---|---|
| ไม่เกิน 50,000 | ผู้จัดการการตลาด | 2 วันทำการ |
| 50,001 - 300,000 | ผู้อำนวยการฝ่าย | 3 วันทำการ |
| 300,001 - 1,000,000 | ผู้จัดการทั่วไป | 5 วันทำการ |
| เกิน 1,000,000 | คณะกรรมการบริษัท | 7 วันทำการ |

## 5. ตัวชี้วัดผลการดำเนินงาน

- สื่อที่ผ่านการตรวจก่อนเผยแพร่: เป้าหมาย 100% (รายเดือน)
- ใช้งบเทียบแผน: เป้าหมาย 95-100% (ต่อแคมเปญ)
- ผลตอบแทนการลงทุนการตลาด (ROI): เป้าหมาย ไม่น้อยกว่า 3 เท่า (ไตรมาส)
- รายงานผลส่งทันเวลา: เป้าหมาย 100% (ต่อแคมเปญ)

## 6. ความเสี่ยงและมาตรการควบคุม

- ข้อความโฆษณาไม่ถูกต้อง: ฝ่ายกฎหมายตรวจก่อนเผยแพร่
- ละเมิดลิขสิทธิ์: ใช้คลังภาพที่ได้รับอนุญาต
- ภาพลักษณ์เสียหายบนโซเชียล: มีแผนตอบสนองและผู้รับผิดชอบเวรตลอดแคมเปญ
- ใช้งบเกิน: ตั้งการแจ้งเตือนที่ 80% ของงบ

## 7. คำถามที่พบบ่อย

**ใช้ภาพจากอินเทอร์เน็ตได้หรือไม่?** ใช้ได้เฉพาะภาพที่มีสิทธิ์ใช้เชิงพาณิชย์และเก็บหลักฐานสิทธิ์

**เปลี่ยนสีโลโก้ได้หรือไม่?** ไม่ได้ ต้องใช้ตามคู่มือแบรนด์เท่านั้น

**จ้างอินฟลูเอนเซอร์ต้องทำอย่างไร?** ทำสัญญา ระบุว่าเป็นโฆษณา และผ่านการตรวจจากฝ่ายกฎหมาย

**งบเพิ่มระหว่างแคมเปญทำอย่างไร?** ขออนุมัติเพิ่มตามตารางวงเงินรวมใหม่

**เผยแพร่ฉุกเฉินข้ามขั้นตอนได้หรือไม่?** ได้เมื่อผู้อำนวยการฝ่ายอนุมัติและตรวจย้อนหลังใน 24 ชั่วโมง
